# References

## Primary sources

- Warner et al., [*Smarter, Better, Faster, Longer: A Modern Bidirectional
  Encoder for Fast, Memory Efficient, and Long Context Finetuning and
  Inference*](https://arxiv.org/abs/2412.13663), 2024.
- [AnswerDotAI ModernBERT research repository](https://github.com/AnswerDotAI/ModernBERT).
- [Hugging Face ModernBERT implementation](https://github.com/huggingface/transformers/blob/main/src/transformers/models/modernbert/modeling_modernbert.py).
- [ModernBERT-base configuration](https://huggingface.co/answerdotai/ModernBERT-base/blob/main/config.json).
- [Laya source repository](https://github.com/NandhaKishorM/laya), especially
  `laya/common.py`, `laya/agent.py`, and the public fine-tuning notebook.
- [Laya model card](https://huggingface.co/convaiinnovations/laya).
- TypeSafe, [*Introducing System One Models &
  Jev*](https://typesafe.ai/blog/introducing-system-one-models-and-jev), 2026.

## Terminology warning

Yang et al.'s 2023
[*RLCD: Reinforcement Learning from Contrastive Distillation for Language Model
Alignment*](https://arxiv.org/abs/2307.12950) uses the same acronym for a
different method. It should not be cited as the training method used in the
decision-model chapters.
